Saves the current game state to an XML file.

Writes the game mode, player moves, result, and statistics to "game_state.xml". If the game mode has changed, statistics are reset. This function is called after each game round to update the saved game state.

Parameters
player1The move chosen by Player 1.
player2The move chosen by Player 2.
resultThe result of the game round.
currentGameModeThe current game mode (e.g., 1 for Man vs AI).
resetStatsIf true, resets statistics when the game mode changes.
